# Cybersecurity Adversary 101

A cybersecurity experiment as a first-ever attempt at a portfolio demonstrating adversary-emulation concepts, detection engineering, defensive automation, and security research.

## Portfolio Structure

Organized around four stages of the adversary lifecycle:

### 01 — Reconnaissance & Preparation
Attack-surface mapping, passive reconnaissance, threat intelligence, DNS analytics, and defensive deception.

### 02 — Discovery
Network and service discovery, API security testing, asynchronous networking, IDS engineering, and protocol analysis.

### 03 — Exploitation & Privilege Escalation
Privilege-escalation research and corresponding endpoint detection engineering.

### 04 — Post-Exploitation
Command-and-control research, persistence, lateral movement, exfiltration concepts, and corresponding defensive detections.

## Engineering Approach

Where appropriate, projects are presented from complementary perspectives:

**Red Team**
- Operational objective
- Technical architecture
- Implementation
- Limitations

**Blue Team**
- Observable behavior
- Detection strategy
- SIEM / IDS implementation
- Mitigation and response
